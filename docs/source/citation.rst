Citation
========

Please cite the corresponding publication (M. Pauls, N. Maser, G. Feldmann, C. Bannwarth, *manuscript in preparation*) and state the dataset version you used. 

Machine-readable citation metadata (authors, version, license) are provided in ``CITATION.cff`` in the root of the repository.

If you use structures, identifiers or functions of ``spectralib`` that build on other software, please cite that software as well (see :doc:`acknowledgments`).
